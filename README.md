# 💰 Expense Tracker

## 📌 Project Description
Expense Tracker is a simple web-based application developed using HTML, CSS, and JavaScript. It helps users manage their daily income and expenses and calculate their available balance.

## 🎯 Objectives
- Track daily income and expenses.
- Calculate the available balance.
- Add and manage transactions.
- View transaction history.
- Save transaction data using Local Storage.

## 🛠️ Technologies Used
- **HTML5** – Creates the structure of the application.
- **CSS3** – Designs and styles the user interface.
- **JavaScript** – Handles calculations and application functionality.
- **Local Storage** – Saves transaction data in the browser.

## ✨ Features
1. Add income transactions.
2. Add expense transactions.
3. Calculate total income.
4. Calculate total expenses.
5. Display available balance.
6. View transaction history.
7. Delete transactions.
8. Store data even after refreshing the browser.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter a transaction description.
5. Enter the amount.
6. Select Income or Expense.
7. Click the Add Transaction button.
8. View your updated balance and transaction history.

## 📸 Project Output

The application displays:
